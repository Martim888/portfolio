## Project Overview

This project is an integrated software solution developed as part of the Computer Engineering degree at Instituto Superior de Engenharia do Porto (ISEP).

The system focuses on industrial production planning, manufacturing process simulation, machine operations and project scheduling.

It combines several software components developed using Java, C, Assembly and Oracle Database technologies to address different challenges related to production management and optimization.

The project also explores graph algorithms, data structures, database management and low-level programming.

## Main Features

### Production Planning & Simulation
- Simulation of manufacturing processes and production operations.
- Management of workstations, operations and production orders.
- Calculation of production times and operational metrics.
- Identification of production bottlenecks.
- Analysis of workstation performance.

### Production Trees & Data Structures
- Representation and management of production trees.
- Processing of operation dependencies.
- Implementation of tree-based data structures, including AVL trees.
- Calculation of material requirements.
- Searching and editing production structures.

### Project Scheduling & Graph Algorithms
- Project planning using PERT/CPM methodologies.
- Critical path identification and analysis.
- Management of dependencies between activities.
- Topological sorting of operations.
- Simulation of project delays.
- Graph-based representation of production processes.

### Database Management
- Relational database modeling using Oracle Database.
- Development of SQL queries and PL/SQL scripts.
- Data manipulation and storage.
- Integration between Java applications and the database.

### Machine Operations & Low-Level Programming
- Development of components using C and Assembly.
- Processing of machine and operation data.
- Implementation of low-level routines.
- Manipulation of arrays, queues and other data structures.

### Data Analysis & Visualization
- Analysis of production metrics and operational performance.
- Export of production and scheduling results.
- Graph-based visualization of dependencies and processes.

## Software Architecture

The project is organized into multiple components addressing different aspects of industrial production management.

**Production Planning Simulator**

A Java application responsible for managing production information, calculating operational metrics, analyzing dependencies and simulating manufacturing processes.

**Database Management**

An Oracle-based component responsible for organizing production data and supporting data processing through SQL and PL/SQL.

**Machine Operations**

Components written in C and Assembly, focusing on low-level data processing and machine-related operations.

**Project Scheduling**

Java components that implement PERT/CPM methodologies to analyze project activities, dependencies and critical paths.

Within the Java application, the source code is organized into packages for user interfaces, controllers, domain models, repositories and graph algorithms.
